---
title: SHA-384
description: SHA-512 with other start values cut to 48 bytes. With HMAC and common in TLS cipher suites
---

::algorithm-facts{name="sha384"}
::

SHA-512 running on its own initial values, with the output cut to 48 bytes. That cut is also why it doesn't suffer the length extension trick plain SHA-256 and SHA-512 do. TLS suites with `SHA384` in the name use it.

```ts
create("sha384").hash("abc").digest;
// "cb00753f45a35e8bb5a03d699ac65007272c32ab0eded1631a8b605a43ff5bed8086072ba1e7cc2358baeca134c825a7"
```

It isn't the first 48 bytes of [SHA-512](/algorithms/sha512). Different start values, different digest.

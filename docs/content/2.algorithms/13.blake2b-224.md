---
title: BLAKE2b-224
description: BLAKE2b with a 28-byte output. Cardano's hash of payment and stake keys and scripts
---

::algorithm-facts{name="blake2b-224"}
::

The 28-byte BLAKE2b behind Cardano's addresses: payment key hashes, stake key hashes, script hashes. Like [BLAKE2b-256](/algorithms/blake2b-256), the length is part of the computation, not a cut afterwards.

```ts
create("blake2b-224").hash("").digest;
// "836cc68931c2e4e3e838602eca1902591d216837bafddfe6f0c8cb07"
```

Hash the key's bytes, so a key you hold as hex goes in through `Uint8Array.fromHex` or `inputEncoding: "hex"`. No HMAC mode.

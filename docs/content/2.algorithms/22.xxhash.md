title: xxHash (XXH64)

::algorithm-facts{name="xxhash"}
::

XXH64, the 64-bit xxHash. Built for speed and good distribution in hash tables, bloom filters and dedup. Anyone can find collisions on purpose.

```ts
create("xxhash").hash("").digest; // "ef46db3751d8e999"
create("xxhash").hash("abc").digest; // "44bc2cf5ad770999"
create("xxhash").hash("abc", { seed: 1 }).digest; // "bea9ca8199328908"
```

The seed is an unsigned 64-bit integer. Past `Number.MAX_SAFE_INTEGER`, pass it as a `bigint` or a decimal string, so `"18446744073709551615"` works and nothing gets rounded. Checked against the reference `xxhash` on hundreds of inputs, after an earlier version of this package got it quietly wrong. That's the regression test's reason to exist.

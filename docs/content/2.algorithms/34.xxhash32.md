---
title: xxHash (XXH32)
description: XXH32 with an optional 32-bit seed. lz4 checks its frames with it
---

::algorithm-facts{name="xxhash32"}
::

XXH32, the 32-bit xxHash. lz4 frames use it three ways: one byte of it closes the frame descriptor, and the full value can follow every block and the whole content.

```ts
create("xxhash32").hash("").digest; // "02cc5d05"
create("xxhash32").hash("abc").digest; // "32d153ff"
create("xxhash32").hash("abc", { seed: 1 }).digest;
```

The seed is an unsigned 32-bit integer, 0 to 4294967295. Printed big-endian, as `xxh32sum` prints it. Checked against the reference C library on inputs across every stripe and tail length.

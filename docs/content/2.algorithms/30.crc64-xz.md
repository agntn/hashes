---
title: CRC-64/XZ
description: The ECMA-182 CRC that xz writes after every block unless you ask for another check
---

::algorithm-facts{name="crc64-xz"}
::

The 64-bit CRC from ECMA-182, reflected, starting and finishing with all ones. xz picks it by default for the check after each block, and `xz -C crc64` asks for it by name. Also known as CRC-64/GO-ECMA.

```ts
create("crc64-xz").hash("123456789").digest; // "995dc9bbdf1939fa", the standard check value
```

Printed big-endian, as the catalogue writes check values. xz stores the eight bytes little-endian, so the end of a `.xz` block reads backwards from this.

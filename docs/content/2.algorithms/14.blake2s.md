---
title: BLAKE2s
description: BLAKE2 for 32-bit platforms with a 32-byte digest and HMAC. Smaller state than BLAKE2b and inside WireGuard
---

::algorithm-facts{name="blake2s"}
::

BLAKE2 on 32-bit words, for the microcontrollers and 32-bit targets where BLAKE2b's 64-bit arithmetic hurts. On a desktop CPU BLAKE2b is usually the faster one.

```ts
create("blake2s").hash("abc").digest;
// "508c5e8c327c14e2e1a72ba34eeb452f37458b209ed63a294d999b4c86675982"
```

WireGuard picked this one. HMAC works here too, over BLAKE2s's 64-byte blocks.

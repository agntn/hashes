---
title: CRC-32/BZIP2
description: The same polynomial as CRC-32, read the other way round. bzip2 stores one per block
---

::algorithm-facts{name="crc32-bzip2"}
::

CRC-32 with the bits taken most significant first and nothing reflected. Same polynomial, same all-ones start and finish, different answer. bzip2 writes one after every block of uncompressed data and folds them into one more for the whole stream.

```ts
create("crc32-bzip2").hash("123456789").digest; // "fc891918", the standard check value
create("crc32").hash("123456789").digest; // "cbf43926", same polynomial, reflected
```

A checksum from a `.bz2` file that matches neither is usually the stream CRC, which rotates the running value left by one bit before each block's CRC goes in. One block means the two agree.

---
title: BLAKE2b
description: BLAKE2b at 64 bytes with HMAC. Fast and unbroken and inside Argon2 and WireGuard
---

::algorithm-facts{name="blake2b"}
::

BLAKE2 for 64-bit machines, at its full 64 bytes. It came out of the SHA-3 competition's BLAKE and got faster instead of slower, which is rare. Argon2 runs on it. WireGuard went with its 32-bit sibling, [BLAKE2s](/algorithms/blake2s).

```ts
create("blake2b").hash("abc").digest;
// "ba80a53f981c4d0d6a2797b69f12f6e94c212f14685ac4b74b12bb6fdbffa2d17d87c5392aab792dc252d5de4533cc9518d38aa8dbf1925ab92386edd4009923"
```

HMAC here is real HMAC over BLAKE2b's blocks. BLAKE2's own keyed mode is a different construction with different output, and the package doesn't implement it.

The shorter variants are separate algorithms, see [BLAKE2b-256](/algorithms/blake2b-256).

---
title: SHA3-512
description: The NIST SHA-3 sponge at 64 bytes with HMAC. The widest SHA-3 the package ships
---

::algorithm-facts{name="sha3-512"}
::

The sponge with a smaller rate and a 64-byte output. Slower than SHA3-256 per byte, since it absorbs less per permutation.

```ts
create("sha3-512").hash("abc").digest;
// "b751850b1a57168a5693cd924b6b096e08f621827444f70d884f5d0240d2712e10e116e9192af3c91a7ec57647e3934057340b4cf408d5a56592f8274eec53f0"
```

[PBKDF2](/algorithms/pbkdf2) can run over it with `digest: "sha3-512"`.

---
title: Argon2d
description: Argon2 with memory reads that follow the data. The fastest to hurt a GPU and the wrong pick when someone shares the machine
---

::algorithm-facts{name="argon2d"}
::

argon2d lets the data pick the next block to read. A cracker can't guess the order, so dropping memory gets expensive fast. The catch? Timing. Those reads follow the password, and a process next to yours can watch them. RFC 9106 points it at cryptocurrencies and proof of work. Nobody sneaks onto that box.

```ts
create("argon2d").hash("password", {
  salt: "73616c7473616c74",
  memory: 1024,
  iterations: 2,
  parallelism: 1,
}).digest;
// "32d03e4754ab2c9369e56f14f9ac2f496ea2b15b75be1d7882b44783f09c5281"
```

A puzzle that says "Argon2" and nothing else? Try all three. The variant is one number in the first hash, and it changes every byte after.

Options, defaults and the byte function `argon2d` from `@agntn/hashes/argon2` work exactly like on the [argon2id](/algorithms/argon2id) page.

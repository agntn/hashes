::algorithm-facts{name="crc32"}
::

The IEEE CRC-32, the one in ZIP, PNG, gzip and Ethernet. It catches accidental bit flips and nothing else. Anyone can forge a CRC-32 in microseconds, since it's linear.

```ts
create("crc32").hash("123456789").digest; // "cbf43926", the standard check value
create("crc32").hash("The quick brown fox jumps over the lazy dog").digest; // "414fa339"
```

The avalanche panel on the landing makes the linearity visible. Flip one input bit and the CRC changes by a pattern that depends only on where that bit sat, not on the rest of the input. A real hash moves a random half. Printed big-endian, as `crc32` tools write it.

---
title: BLAKE2b-256
description: BLAKE2b with a 32-byte output. Sui addresses and Cardano transaction ids. Not half of the 64-byte digest
---

::algorithm-facts{name="blake2b-256"}
::

BLAKE2b told up front to produce 32 bytes. The length goes into the parameter block, so the digest isn't the first half of [BLAKE2b](/algorithms/blake2b)'s:

```ts
create("blake2b-256").hash("abc").digest;
// "bddd813c634239723171ef3fee98579b94964e3bb1cb3e427262c8c068d52319"
create("blake2b").hash("abc").digest.slice(0, 64);
// "ba80a53f981c4d0d6a2797b69f12f6e94c212f14685ac4b74b12bb6fdbffa2d1", not the same
```

That's the mistake worth a page. Sui derives addresses with it, Cardano names transactions with it, and truncating the long one gives a digest that looks fine and that nobody will ever match. No HMAC mode.

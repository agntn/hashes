---
title: CRC-64
description: The ECMA-182 CRC that xz writes after every block unless you ask for another check
---

::algorithm-facts{name="crc64"}
::

The 64-bit CRC from ECMA-182, reflected, starting and finishing with all ones. xz picks it by default for the check after each block, and `xz -C crc64` asks for it by name. The catalogue calls it CRC-64/XZ, or CRC-64/GO-ECMA.

```ts
create("crc64").hash("123456789").digest; // "995dc9bbdf1939fa", the standard check value
crc64(bytes, "xz"); // the byte function, same thing
```

`variant` has one value so far, `xz`. It's there so the next CRC-64 lands as a value, not as another algorithm. Printed big-endian, as the catalogue writes check values. xz stores the eight bytes little-endian, so the end of a `.xz` block reads backwards from this.
